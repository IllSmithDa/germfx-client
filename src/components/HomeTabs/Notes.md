Architecture — Since page.tsx is a Next.js Server Component, tab state can't live there. The solution is a new HomeTabs client component ("use client") that receives both medications and logs as plain serializable props from the server, and owns the useState for which tab is active. The server still does all data fetching.
Tab design — Tabs use a raised card style: the active tab has a card background + border with the bottom edge erased (using a 1px pseudo-element matching the card background), making it appear connected to the content below — a classic but polished tab pattern. Inactive tabs are ghost-styled with a hover background.
Tab badges — Each tab shows a count badge: the Medications tab badge turns green when there are active medications, the Logs tab uses the standard muted style.
Sub-header context — Each panel shows a contextual subtitle ("2 active · 1 inactive" or "12 entries across 5 days") just below the tab bar, so users get a summary before scrolling into the list.
page.tsx cleanup — The mapRecentLogs + logsForList remapping steps are consolidated into a single mapLogsForList function that produces SymptomLogListItem[] directly, removing the intermediate UISymptomLog step that was only there to then be re-mapped again.
