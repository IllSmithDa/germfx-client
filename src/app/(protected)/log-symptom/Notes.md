# UI notes on log symptoms

  1. Section headings with subtitles — Both "Find a Drug" and "My Medications" have a heading + muted subtitle, giving the page clear navigational anchors.

  2. Active/inactive stat badges — The medications header shows live-counted green "X active" and gray "X inactive" badges, providing a summary at a glance without needing to count cards.

  3. Smarter empty state subtitle — When no medications exist, the subtitle reads "Search for a drug above to add it to your list" — a gentle call-to-action pointing to the search bar.

  4. Responsive padding — py-6 sm:py-10 gives tighter padding on mobile where vertical space is scarcer.
